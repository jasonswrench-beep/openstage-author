# Looks

A short example of object states, which the editor calls looks (format 0.24.0), made with the editor itself.

| Slide | What it shows |
| --- | --- |
| Mark a step as done | A step, and two buttons. **Mark done** gives the step a look of its own, Done (bigger and a dark green), and a screen reader says "Step 1 is marked as done". **Not done yet** puts the step back to normal, which says nothing. Both buttons have a Hover look, and Mark done has a Visited look: press it and it changes colour. |
| A button that is not ready yet | **Submit** starts in the ready-made Disabled look: it is dimmed, cannot be pressed, and a screen reader says it is unavailable. **Unlock Submit** gives it a look of its own, Ready (teal), and a screen reader says "Submit is ready". |
| Finished | Press Back and try again: the looks start over each time a slide opens. |

Open it in the editor and select a button or the step to see its **Looks** box. The rules are on the buttons, under **Rules**: Do **Change an object's look**.
The colours were chosen so that every look reads well (the validator checks text in each look, and in looks stacked together). The two Next and Back buttons use icons from Lucide (ISC licence), so the credits page is on.
